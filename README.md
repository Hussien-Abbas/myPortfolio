# 🌐 Personal Portfolio | Hussien Abbas

A high-end, high-performance personal portfolio website built with a **Modern Dark Techy Aesthetic**. This project was designed to showcase my journey as a **Flutter & Full-Stack Engineer**, highlighting my technical skills, professional training, and key projects.

---

## ✨ Features & UI/UX Highlights

* **Modern Dark UI:** Deep midnight theme with neon cyan and violet accents, featuring **Glassmorphism** and subtle background glows.
* **Fully Responsive:** Engineered with a **Mobile-First** approach using **Tailwind CSS**, ensuring a seamless experience across all devices.
* **Interactive Elements:** Includes a **Typewriter effect** for roles, **animated counters** for stats, and **reveal-on-scroll** animations.
* **Single-File Architecture:** Optimized into a single `index.html` for rapid deployment and maximum performance.
* **Direct Contact Integration:** Functional links for Email, LinkedIn, GitHub, and a dedicated **CV Download** button.

---

## 🛠️ Technical Stack

* **Frontend:** HTML5, CSS3 (Custom animations & Gradients).
* **Styling:** **Tailwind CSS** (Utility-first framework for modern layouts).
* **Interactions:** Vanilla **JavaScript** (Intersection Observer API for animations & DOM manipulation).
* **Icons:** **Lucide Icons** for a crisp, scalable look.
* **Typography:** Syne & JetBrains Mono for that "Engineer-centric" feel.

The site is ready to be hosted on any static hosting provider.

2.  **Vercel/Netlify:** Drag and drop the `index.html` file for instant deployment.
